## Abstract

In this paper, we demonstrate how to leverage 2:4 sparsity, a popular hardware-accelerated GPU sparsity pattern, to activations to accelerate large language model training and inference. Crucially we exploit the intrinsic sparsity found in Squared-ReLU activations to provide this acceleration with no accuracy loss. Our approach achieves up to 1.3x faster Feed Forward Network (FFNs) in both the forwards and backwards pass. This work highlights the potential for sparsity to play a key role in accelerating large language model training and inference.

## Contributions (from the paper)

In this paper, we investigate the application of 2:4 sparsity to accelerate both LLM training and inference by sparsifying model activations. Crucially, we exploit the intrinsic sparsity found in certain activation functions, which is not present in the dense model weights. Our main contributions are as follows: A recipe to accelerate Squared-RELU LLM training and inference with 2:4 sparsity. Accuracy experiments showing minimal performance degradation when using our emulated recipe compared to the dense baseline. Kernel benchmarks showing up to 1.3x faster FFNs when using 2:4 sparsity. Squared ReLU: Recently, SwiGLU = (Swish_{\beta}(XW_{1})\odot XW_{3})W_{2} (Shazeer, 2020) has been used as the activation function in the Feed-Forward Network blocks (FFN) of multiple LLMs (Touvron et al., 2023) (Liu et al., 2024a). However, (So et al., 2021) suggests that Squared-ReLU = ({\max(0,XW_{1})}^{2})W_{2} is at least as good as SwiGLU, which we confirmed in our experiments (Table1). Larger models have since been trained successfully with Squared-ReLU (Adler et al., 2024).

| Experiment | Final Perplexity |
| --- | --- |
| Dense training (SwiGLU) | 2.654 |
| Dense training (Squared-ReLU) | 2.651 |
| 2:4 recipe (5% of the features dense in BW) | 2.652 |
| 2:4 - no warmup | 2.657 |
| 2:4 - naively sparsify backward GEMMs | 2.682 |
| 2:4 - no permuting rows | 2.919 (plateaus very early) |
| 2:4 - no sparsify $y_{1}$ in BW pass | 3.735 (diverges after step $\sim$42k) |
